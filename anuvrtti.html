Anuvṛtti

Carried words as the file records them on 1.1.3.

Learn it in 5 minutes

3489 of the 3,983 rows have a non-empty anuvritti array. The other rows have an empty array. That is a count, not a theory.

Learner's note (not a translation): classrooms use anuvṛtti for words that carry forward from an earlier line so the later line can stay short. This app shows the strings the file stored. It does not decide whether a string was carried correctly.

On 1.1.3 the Devanāgarī is इको गुणवृद्धी. The file's IAST is iko guṇavṛddhī and is script-converted, not yet human-checked. The anuvritti field lists: वृद्धिः, गुणः.

The padaccheda field on that row is also stored in the file. It is shown as file data, not as this project's analysis. Meaning: not yet sourced from an open text.

Foundations, dependencies, history, roadmap

Dependencies. Aṣṭādhyāyī structure, so the number 1.1.3 is meaningful.

History. No date is added on this page.

Roadmap. Show a chain of carried strings across several rows, still without translating them.

Where the idea shows up. Compression in a rule list is interesting to programming-language people. Calling anuvṛtti a macro is a learner's bridge. Confirm before relying if you say it in an interview as history.

Worked example

Read 1.1.3 as a file row

  1. Number: 1.1.3. Type letter: P. The meta calls P paribhāṣā.
  2. Devanāgarī: इको गुणवृद्धी.
  3. anuvritti array: वृद्धिः, गुणः.
  4. padaccheda from the file: गुणः, वृद्धिः (इत्येताभ्यां निर्दिष्टौ) गुण-वृद्धी इकः.
  5. Stop before an English rendering. There isn't a confirmed open one in this project.
