Sūtra Nexus

A free offline study of Sanskrit sound and grammar, with the gaps labeled.

Learn it in 5 minutes

Sūtra Nexus is a free study desk for three open data files: 3,983 Aṣṭādhyāyī lines, 14 Māheśvara lines, and 75 Kashmir Śiva Sūtras. It is a learning project by a lifelong student and AI enthusiast moving toward AI omni-channel agents.

The start path has six steps. Progress marks stay in this browser. Nothing is uploaded.

Meaning field for every canon line in this app: meaning: not yet sourced from an open text. IAST from the Aṣṭādhyāyī file is script-converted, not yet human-checked.

A short plain-English line in this app is a learner's note (not a translation). It teaches how the app is organized. It is not a scholar's rendering of a sūtra.

Foundations, dependencies, history, roadmap

Dependencies. None. This is the front door.

History. Dates are on the history page, and only as the opened article states them.

Roadmap. Next: an open-licensed meaning, then a human check of the IAST.

Where the idea shows up. People compare rule lists with programming and with linguistics. Those comparisons in this app are learner's bridges, not claims about Pāṇini's intent. Confirm before relying.

Worked example

Read the number 1.1.1

  1. The file stores the number 1.1.1 on the first row.
  2. The digits mean chapter 1, section 1, line 1. English Wikipedia's Aṣṭādhyāyī page, checked 2026-10-16, says eight chapters each subdivided into four sections.
  3. The Devanāgarī on that row is वृद्धिरादैच्. The file's IAST is vṛddhirādaic and is script-converted, not yet human-checked.
  4. The meaning is not yet sourced from an open text. This example stops there on purpose.
